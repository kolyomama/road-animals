# Пътят не е само за хора

Уебсайт на младежка образователно-информационна кампания за пътна екология и опазване на уязвими земноводни и влечуги (костенурки, жаби, гущери, змии).

Кампанията се реализира от Фондация „Шанс за децата и природата на България“ и Център за млади таланти – Бургас.

## Технологии

- React + Vite (TanStack Start)
- Tailwind CSS и shadcn/ui компоненти
- Първоначално генериран с Lovable, оттук нататък се развива самостоятелно в това хранилище

## Локално стартиране

```bash
npm install
npm run dev
```

## Структура

- `src/routes/index.tsx` — началната страница със всички секции
- `src/routes/__root.tsx` — основен шаблон, мета данни и SEO
- `src/styles.css` — цветове и общ стил
- `src/components/ui/` — готови UI компоненти
